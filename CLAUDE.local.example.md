# CLAUDE.local.example.md

Optional local-only communication preferences for a founder/operator.

Copy this file to `CLAUDE.local.md` and customize it. Keep `CLAUDE.local.md` gitignored.

Example preferences:
- use plain English
- start with a short summary
- use clear hierarchy and short sections
- prefer concrete examples and diagrams
- distinguish must-build-now from later
- recommend a sensible default rather than many equivalent choices
- explain what changed and why
- flag assumptions and uncertainty
